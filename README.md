## 这是什么

保研要提前多久准备、哪些竞赛值得参加、奖学金怎么评、选调和国考有什么区别——这些信息散落在学长学姐的经验、群聊和各种通知里，每一届都要重新打听一遍。

**Awesome JMU CEC** 把它们整理成可以搜索、可以长期更新的文章，放在一个地方。每篇文章都来自同学投稿，任何人都可以修正和补充。

## 网站功能

- **中文全文搜索**：按汉字分词，简称和全称互通（搜「推免」能找到「保研」，搜「国奖」能找到「国家奖学金」）。
- **[重要日期](https://awesome-jmu-cec.pages.dev/calendar/)**：考研报名、四六级、国考等节点，带倒计时；可以订阅到手机日历，提前提醒。
- **[问答](https://awesome-jmu-cec.pages.dev/questions/)**：在 GitHub 上提问，问题会同步显示在网站和对应板块，学长学姐直接回复；关闭后自动消失。
- **[校园地图](https://awesome-jmu-cec.pages.dev/map/)**：3D 建筑、地点搜索，手机上能显示你的位置（只在浏览器里计算，不上传）。
- **纠错与补充**：每篇文章末尾都有「报告错误」「补充内容」按钮，标题和页面地址自动填好。
- **为手机设计**：深浅色模式、可左右滑动的四年路线、文章图片点按放大、底部可拖动的地图面板。

## 参与贡献

本站的每一篇文章都来自同学投稿，**不需要会写代码**。

| 想做什么 | 怎么做 |
| --- | --- |
| 写一篇文章 | 按 [投稿指南](https://awesome-jmu-cec.pages.dev/contribute/) 在 GitHub 网页上新建一个 Markdown 文件，几分钟就能完成；[指南模板](templates/guide.md)、[经验帖模板](templates/experience.md) |
| 改一处错误 | 文章末尾点「报告错误」，或者点「在 GitHub 上编辑此页」直接修改 |
| 问个问题 | 到 [问答](https://awesome-jmu-cec.pages.dev/questions/) 点「我要提问」 |
| 补一个重要日期 | 编辑 [`docs/calendar/events.yaml`](docs/calendar/events.yaml)，附上官方来源 |
| 修正地图上的地点 | 编辑 [`docs/map/places.yaml`](docs/map/places.yaml) |
| 不会用 GitHub | 在 [Issues](https://github.com/K1nesss/Awesome-jmu-cec/issues/new/choose) 里把内容贴进来，维护者代为发布并保留署名 |

几条规则：

- **只写自己确认过的信息**，政策类内容注明年份、尽量附官方链接。
- **保护隐私**：不出现他人的姓名、学号、联系方式或聊天截图。
- **涉及老师只写公开信息**（研究方向、实验室、官方主页、进组经历），不写评分、评价或传闻。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
git clone https://github.com/K1nesss/Awesome-jmu-cec.git
cd Awesome-jmu-cec
npm install
npm run dev        # 本地预览：http://localhost:5173
```

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发预览，改文章实时刷新（新增文件后重启才会进侧栏） |
| `npm run build` | 检查 frontmatter 与图片，然后构建到 `docs/.vitepress/dist` |
| `npm test` | 运行测试（搜索分词、日历、地图数据等） |
| `npm run map:build` | 更新 OpenStreetMap 数据后，重新生成校园地图数据 |

## 部署

网站托管在 [Cloudflare Pages](https://pages.cloudflare.com/)：推送到 `main` 后自动构建（构建命令 `npm ci && npm run build`，输出目录 `docs/.vitepress/dist`），Pull Request 有预览部署。

| 配置 | 位置 | 用途 |
| --- | --- | --- |
| `GITHUB_READ_TOKEN` | Cloudflare Pages 环境变量 | 构建时读取问答与贡献者（只读令牌） |
| `CLOUDFLARE_DEPLOY_HOOK` | GitHub 仓库 Secret | 有人提问或关闭提问时触发重新构建 |

Web Analytics 在 Cloudflare 后台开启，不使用 Cookie。
