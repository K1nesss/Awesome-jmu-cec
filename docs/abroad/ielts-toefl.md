# 雅思与托福备考

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。具体要求以目标学校官网和当年通知为准，欢迎有经验的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

语言成绩是留学申请的硬门槛。两种考试大多数学校都接受，先选一种专心准备即可。

## 两种考试对比

| | 雅思（学术类） | 托福 iBT |
|---|---|---|
| 满分 | 9 分（四项各 9 分，取平均） | 120 分（四项各 30 分） |
| 考试科目 | 听、说、读、写 | 听、说、读、写 |
| 口语形式 | 与考官面对面 | 对电脑录音 |
| 成绩有效期 | 一般认可两年内的成绩 | 一般认可两年内的成绩 |
| 常见认可地区 | 英国、澳洲、中国香港、新加坡等 | 美国，以及大多数其他地区 |

::: warning 注意
托福在 2026 年起有改版（题型与计分方式有调整），备考前请以 ETS 官网的最新说明为准。
:::

## 常见分数要求

不同学校和专业差别很大，下面只是常见范围：

- **雅思**：总分 6.5，单项不低于 6 是很多授课型硕士的常见要求，名校或部分专业会更高。
- **托福**：常见要求在 90–100 分之间，部分项目对口语或写作有单项要求。

一定以目标项目官网写明的要求为准。

## 备考节奏建议

1. **先做一套真题摸底**，知道自己离目标差多少。
2. **按短板分配时间**：多数中国学生的口语和写作提分最慢。
3. **预留二刷时间**：第一次没考到很常见，至少留出一次重考的时间。
4. **提前报名考位**：申请季前后考位紧张，最好提前一两个月预约。
