# 申请全流程时间线

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。具体要求以目标学校官网和当年通知为准，欢迎有经验的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

以**本科毕业当年秋季入学**的硕士申请为例。大多数地区的申请都在大四上学期集中进行，所以真正的准备要从大三甚至大二开始。

## 时间线

| 时间 | 要做的事 |
|---|---|
| 大二下 – 大三上 | 确定目标地区与专业方向，开始准备语言考试 |
| 大三下 | 考出语言成绩；有需要的方向准备 GRE |
| 大三暑假 | 确定选校清单，开始写个人陈述与简历，联系推荐人 |
| 大四上（约 9–12 月） | 集中提交申请；英国、中国香港等地区不少项目滚动录取，宜早不宜迟 |
| 大四上 – 大四下 | 陆续收到面试与录取结果，比较后确认去向、缴纳留位费 |
| 大四下 – 毕业 | 办理签证、住宿，提交毕业证与学位证 |

## 不同地区的节奏差异

- **英国、中国香港、新加坡**：开放申请早，很多项目先到先得，越早投越有利。
- **美国**：截止日期相对集中，常见在 12 月到次年 1 月。
- **澳大利亚**：一年有多个入学批次，时间比较灵活。

## 容易忽略的事

- **成绩单与在读证明**：中英文版本都要准备，部分学校需要密封件。
- **推荐信**：提前一到两个月和老师沟通，给老师留足时间。
- **预算**：申请费、语言考试费、留位费加起来是一笔不小的支出。
