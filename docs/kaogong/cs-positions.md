# 计算机专业可以报哪些岗位

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

计算机类专业在考公时选择面比较宽：除了不限专业的岗位，还有不少明确要求计算机、软件、网络安全等专业的技术岗位，竞争往往比不限专业的岗位小。

## 怎么在职位表里筛选

1. 下载当年招录公告附带的**职位表**（一般是 Excel）。
2. 在“专业”一栏搜索 **计算机**、**软件**、**网络**、**信息安全** 等关键词。
3. 同时筛选“不限专业”的岗位，作为备选。
4. 逐条核对学历、学位、政治面貌、基层工作经历等其他条件。

::: tip 专业名称要对得上
职位表写的是专业类或具体专业名称。有的地区会发布专业参考目录，拿不准时以招录机关的解释为准，可以打电话咨询职位表上的联系电话。
:::

## 常见的技术类岗位

| 系统 | 常见岗位方向 |
|---|---|
| 公安机关 | 网络安全、信息通信等技术岗（人民警察岗位另有体能测评与体检要求） |
| 海关 | 信息技术、数据分析类岗位 |
| 税务 | 信息技术岗 |
| 统计 | 数据处理、信息化岗位 |
| 法院、检察院 | 信息化、技术支持岗位 |

## 备考提示

- 技术岗与其他岗位考同样的**行测和申论**，专业能力一般在面试或专业科目中考查。
- 部分岗位有**专业科目考试**，报名前看清公告。
