# 国考、省考与选调生有什么区别

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

“考公”通常指三类考试：国家公务员考试（国考）、地方公务员考试（省考）和选调生考试。它们的招录单位、时间和条件都不一样。

## 一张表看区别

| | 国考 | 省考 | 选调生 |
|---|---|---|---|
| 招录单位 | 中央机关及其直属机构 | 省、市、县、乡镇机关 | 各省党委组织部门，面向基层 |
| 报考对象 | 符合条件的社会人员与应届生 | 符合条件的社会人员与应届生 | 主要面向应届毕业生 |
| 大致时间 | 通常 10 月中下旬报名，11 月底或 12 月初笔试 | 多数省份参加联考，笔试一般在春季 | 各省自定，多在秋冬或春季 |
| 考试内容 | 行测 + 申论 + 面试 | 行测 + 申论 + 面试 | 各省不同，常见为行测、申论或综合能力测试 + 面试 |

## 选调生的特点

- **面向应届生**：多数省份只招当年毕业生，错过就没有了。
- **条件更具体**：常见要求包括中共党员（含预备党员）、担任过学生干部、获得过奖学金等，具体以各省公告为准。
- **到基层锻炼**：一般先在乡镇或基层单位工作一段时间。
- **定向与非定向**：部分省份有面向特定高校的“定向选调”，其余为普通选调。

## 怎么选

1. **先看条件**：选调生条件最具体，先确认自己是否符合。
2. **再看时间**：国考在先，省考和选调在后，可以都报，以考代练。
3. **最后看去向**：想去中央单位选国考，想回家乡选对应省份的省考或选调。
