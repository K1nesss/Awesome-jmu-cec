# 奖学金类型总览

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。具体要求以目标学校官网和当年通知为准，欢迎有经验的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

本科阶段常见的奖励和资助分为两类：**国家层面**的奖助学金，以及**学校、学院、社会捐赠**设立的奖学金。

## 国家层面的三类

| 名称 | 面向谁 | 主要看什么 |
|---|---|---|
| 国家奖学金 | 二年级及以上学生 | 学习成绩、综合表现特别优秀 |
| 国家励志奖学金 | 二年级及以上、家庭经济困难的学生 | 品学兼优 |
| 国家助学金 | 家庭经济困难的学生 | 家庭经济情况 |

几条常见规则：

- 同一学年内，**国家奖学金和国家励志奖学金不能同时获得**；
- 国家助学金可以与国家奖学金或国家励志奖学金**同时获得**；
- 申请励志奖学金和助学金，一般需要先完成家庭经济困难学生认定。

金额会随国家政策调整（例如 2024 年起有过提高），以当年文件为准。

## 学校与社会奖学金

- **校级、院级奖学金**：通常按综合测评排名评定，分若干等级；
- **单项奖学金**：如学业进步、科技创新、文体活动等；
- **企业、校友捐赠的奖学金**：评选条件各不相同，留意学院通知。

## 申请建议

1. **看懂综合测评**：大部分校内奖学金都和综测挂钩，详见《综合测评怎么算》。
2. **留好证明材料**：获奖证书、志愿时长、活动证明平时就整理好。
3. **按时提交**：评选通常在秋季学期初进行，错过很难补。
