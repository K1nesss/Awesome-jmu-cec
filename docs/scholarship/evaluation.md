# 综合测评怎么算

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。具体要求以目标学校官网和当年通知为准，欢迎有经验的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

综合测评（简称“综测”）是很多校内奖学金、评优评先的依据。各校的计算办法差别很大，下面介绍的是**常见的结构**，请务必找到本学院当年的综测细则对照阅读。

## 常见的组成

| 部分 | 通常包含 | 说明 |
|---|---|---|
| 智育 | 课程成绩、学分绩点 | 一般占比最大 |
| 德育 | 思想表现、遵纪守法、志愿服务 | 常有基础分加奖励分 |
| 体育 | 体育课成绩、体测、体育比赛 | |
| 美育、劳育 | 文艺活动、劳动实践 | 部分学校单列 |
| 加分项 | 竞赛获奖、科研成果、学生工作 | 通常有上限 |

最终成绩一般是各部分按比例加权求和，例如“智育占大头，其余各占一部分”，具体比例以细则为准。

## 平时怎么积累

- **成绩是基础**：智育占比通常最高，其他部分很难弥补成绩上的差距。
- **加分有上限**：同类加分常有封顶，与其多拿同类证书，不如补齐没有覆盖到的部分。
- **证明材料要留存**：活动结束后及时保存证书、截图或证明，评选时临时找往往来不及。

## 常见问题

- **对结果有疑问怎么办**：综测结果一般会公示，公示期内可以向班级或学院提出复核。
- **转专业后怎么算**：通常按转入专业的办法计算，具体问学院。
