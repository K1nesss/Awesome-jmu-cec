# 关于本站

**Awesome JMU CEC** 是一个面向集美大学计算机工程学院本科生的信息差百科，把散落在学长学姐经验、群聊和各类通知里的信息，整理成可以搜索、可以长期更新的文章。

## 涵盖内容

全站分三个大类：

- **了解学院**：学院与专业、导师与科研；
- **在校学习与生活**：大学四年规划、课程与学业、竞赛、奖学金、校园生活；
- **毕业去向**：保研、考研、就业与实习、考公·选调、留学。

## 免责声明

- 本站是同学自发维护的**非官方项目**，不代表集美大学或计算机工程学院的立场。
- 文章由投稿者撰写，可能存在过时或不准确之处；涉及政策、名额、时间节点的内容，请以学校与学院发布的最新通知为准。
- 发现错误？欢迎点击页面底部的「在 GitHub 上编辑此页」直接修正，或在 [Issues](https://github.com/K1nesss/Awesome-jmu-cec/issues) 反馈。

## 搜索小提示

站内搜索按汉字匹配，**暂不支持拼音**（例如搜「保研」可以，搜 `baoyan` 不行）。按 <kbd>Ctrl</kbd> + <kbd>K</kbd>（Mac 上是 <kbd>⌘</kbd> + <kbd>K</kbd>）可随时打开搜索。
