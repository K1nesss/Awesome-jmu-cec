# 如何组队与找指导老师

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

团队赛的结果，一半取决于组队。下面是一些通用经验。

## 去哪里找队友

- **同班、同实验室的同学**：最容易约时间。
- **学院竞赛群、往届参赛同学**：学长学姐通常愿意介绍人。
- **校内选拔赛**：一起参加过选拔的人，水平和投入程度都看得见。

## 怎么分工

以三人队为例，常见的分工是：

| 角色 | 负责 |
|---|---|
| 主力 / 队长 | 把控进度，负责最难的部分 |
| 实现 | 写代码或做作品的主体 |
| 文档 / 展示 | 论文、答辩材料、路演 |

分工不必固定，但**最好在比赛前就说清楚**，避免临场推诿。

## 怎么联系指导老师

1. **先了解老师的方向**：看学院官网的教师介绍和近几年带过的比赛。
2. **带着具体内容去**：说明想参加什么比赛、团队情况、目前的想法。
3. **邮件或当面都可以**：邮件写清楚姓名、年级、专业和联系方式，语气礼貌、简洁。

## 常见问题

- **队友中途退出**：提前约定好投入时间；真退出了，尽快在群里补人。
- **能力差距大**：比赛前一起刷几套往年题，比空谈分工更能磨合。
