# 计算机类竞赛清单与含金量

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

“含金量”通常看两点：**是否被学校认定**（保研加分、综测加分时会用到），以及**在业内的认可度**。很多学校参考中国高等教育学会发布的“全国普通高校大学生竞赛排行榜”竞赛目录，具体以学院的认定文件为准。

## 算法与程序设计类

| 竞赛 | 形式 | 大致时间 | 适合谁 |
|---|---|---|---|
| ICPC 国际大学生程序设计竞赛 | 三人一队，现场限时解题 | 区域赛多在秋季 | 愿意长期刷题的同学 |
| CCPC 中国大学生程序设计竞赛 | 与 ICPC 类似 | 多在秋季 | 同上 |
| 蓝桥杯 | 个人赛，分省赛、国赛 | 省赛多在春季 | 入门友好，适合第一次参赛 |
| 团体程序设计天梯赛 | 团队成绩、个人答题 | 多在春季 | 想积累比赛经验的同学 |

## 综合与创新类

| 竞赛 | 形式 | 适合谁 |
|---|---|---|
| 中国大学生计算机设计大赛 | 提交作品并答辩 | 有完整作品的小团队 |
| 中国国际大学生创新大赛（原“互联网+”） | 项目路演 | 有创业或应用项目的团队 |
| “挑战杯”系列竞赛 | 学术作品 / 创业计划 | 有科研或创业项目的团队 |
| 全国大学生数学建模竞赛 | 三人一队，连续几天完成论文 | 数学与编程都不错的同学 |

## 怎么选第一个比赛

- **只想试试**：从个人赛开始，例如蓝桥杯，准备成本低，能快速知道自己是否喜欢。
- **想冲保研加分**：先查学院认定的竞赛目录和级别，再决定投入。
- **想找实习**：作品类、项目类比赛的成果可以直接写进简历。

报名时间每年都可能变动，请关注官网和学院通知。
