# 毕业去向怎么选：保研、考研、就业、考公、留学

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

没有哪条路天然更好。比较实际的做法是：先看自己现在的条件，再看每条路需要的准备时间，**越晚决定，可选的路越少**。

## 五条路的对比

| 去向 | 适合谁 | 关键门槛 | 什么时候开始准备 |
|---|---|---|---|
| 保研 | 前几个学期排名靠前 | 专业排名、竞赛与科研经历 | 大一起守绩点，大三上冲刺 |
| 考研 | 想读研但排名不够保研 | 初试分数线、复试 | 大三上定目标，大三暑假全面复习 |
| 就业 | 想尽早工作、有项目经验 | 实习经历、项目与刷题 | 大二开始做项目，大三暑期实习 |
| 考公 / 选调 | 想进体制内 | 报考条件、笔试与面试 | 大三了解政策，大四上参加考试 |
| 留学 | 预算允许、想换个环境 | 语言成绩、绩点、文书 | 大二规划语言，大三考出成绩 |

## 怎么做决定

1. **先看硬条件**：排名、语言成绩、家庭预算，这些会直接排除一部分选项。
2. **问问走过这条路的人**：每个板块的经验帖就是为此准备的。
3. **留一条后路**：例如准备保研的同学同时准备考研复习，冲留学的同学留意秋招。

## 常见误区

- **“大四再说”**：保研要看前几个学期的成绩，留学要提前一年申请，等到大四很多选项已经关上了。
- **“别人都在考研，我也考”**：读研的目的想清楚，比跟风重要得多。
