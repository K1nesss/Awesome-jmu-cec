# 四年时间线总览

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

大学四年里，很多机会都有固定的时间窗口：错过了不是不能补，而是要多花不少力气。这篇文章按学年列出最常见的节点，细节请点进对应板块。

## 大一：打基础，摸清规则

- **开学第一个月**：找到本专业的培养方案，弄清毕业要修多少学分、哪些是必修。
- **第一学期**：高数、线代、程序设计等基础课决定了绩点的底子，后面想保研或拿奖学金都绕不开它。
- **全年**：了解综合测评和奖学金的评定办法，社团、志愿活动按兴趣参加即可，不必贪多。
- **第二学期**：如果想转专业，留意学校发布的通知时间。

## 大二：找方向，攒经历

- **参加第一个竞赛或项目**：不求拿大奖，重点是知道自己喜欢做什么。
- **英语四六级**：大多数同学在大一下或大二考完四级，再考六级。
- **想留学的同学**：开始了解目标地区的要求，规划语言考试的时间。

## 大三：做决定，提前准备

大三是分岔口，**保研、考研、考公、留学、就业**的准备节奏完全不同：

| 方向 | 大三要做的事 |
|---|---|
| 保研 | 守住排名，三月起关注夏令营报名 |
| 考研 | 确定院校与专业，暑假进入全面复习 |
| 考公 / 选调 | 了解报考条件，准备行测申论 |
| 留学 | 考出语言成绩，暑假准备文书 |
| 就业 | 暑期实习是秋招前最重要的经历 |

## 大四：落实去向

- **上学期**：推免、研究生考试、国考与留学申请集中在这段时间。
- **下学期**：完成毕业设计与答辩，办理离校手续。
- **最后**：把你踩过的坑写下来，留给下一届。
