# 保研全流程时间线

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

保研（推荐免试攻读研究生）本质上分两步：先在本校**拿到推免资格**，再到目标学校**拿到录取**。两步的时间线是交错进行的。

## 大一到大三上：守住排名

推免资格主要看前几个学年（或前五个学期）的**学业成绩排名**，部分学校还会计入竞赛、科研等加分。这一阶段最重要的事就是：

- 把专业课成绩稳住，尤其是学分高的课程；
- 了解学院的推免细则，知道哪些竞赛、论文能加分；
- 有余力时进实验室或参加竞赛，为简历积累内容。

## 大三下：准备材料、报名夏令营

| 时间 | 要做的事 |
|---|---|
| 3–5 月 | 关注目标院校夏令营通知，准备简历、个人陈述、推荐信 |
| 5–6 月 | 陆续提交夏令营报名材料 |
| 6–7 月 | 等待入营结果，准备面试与机试 |

## 大三暑假：夏令营

夏令营一般包括宣讲、笔试或机试、面试。表现优秀的同学可能拿到“优秀营员”，后续录取时更有优势。

## 大四上：资格确认与正式录取

| 时间 | 要做的事 |
|---|---|
| 8–9 月 | 参加预推免（也常被叫作“九推”），争取更多机会 |
| 9 月 | 学校公示推免资格名单 |
| 9 月下旬起 | 在“全国推荐优秀应届本科毕业生免试攻读研究生信息公开暨管理服务系统”填报志愿、参加复试 |
| 随后 | 接受待录取通知，确认后录取结果锁定 |

::: warning 注意
确认待录取后通常不能再更改，填报和确认前务必想清楚。
:::
