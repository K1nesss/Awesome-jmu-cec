# 夏令营怎么准备

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。学院的具体规定（名额、比例、时间）以当年通知为准，欢迎熟悉情况的同学点击页面底部「在 GitHub 上编辑此页」补充。

夏令营是保研中最重要的一环：很多学校的推免名额会优先给夏令营中的“优秀营员”。

## 报名材料清单

大多数学校会要求以下材料，提前准备好电子版，报名季会轻松很多：

- **个人简历**：一页为宜，突出成绩排名、竞赛与科研经历；
- **成绩单与排名证明**：一般需要教务处或学院盖章；
- **英语成绩**：四六级、雅思或托福；
- **个人陈述**：说明为什么选择这个方向、做过什么、读研想做什么；
- **推荐信**：通常需要两位老师，提前和老师沟通；
- **获奖证书、论文等证明材料**。

## 面试常见问题

| 类型 | 例子 |
|---|---|
| 自我介绍 | 中文或英文，控制在两三分钟 |
| 专业基础 | 数据结构、操作系统、计算机网络等课程的基本概念 |
| 项目经历 | 你在项目里具体做了什么，遇到过什么困难 |
| 研究兴趣 | 为什么想做这个方向，读过哪些相关论文 |

## 机试准备

计算机方向的部分院校会安排机试，题目类似程序设计竞赛的入门到中等难度。建议提前几个月开始，每周固定刷题，熟悉常用的数据结构与算法。

## 时间安排建议

- **报名要多投**：入营结果有不确定性，多报几所梯度不同的学校。
- **注意时间冲突**：不同学校的夏令营可能撞期，提前排好优先级。
