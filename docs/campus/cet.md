# 英语四六级报名与备考

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。具体要求以目标学校官网和当年通知为准，欢迎有经验的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

大学英语四、六级考试（CET）每年举行两次，通常在 **6 月和 12 月**。很多奖学金、保研、求职场景都会看四六级成绩。

## 报名

- 通过**学校组织**统一报名，一般在考前两三个月，留意教务处或学院通知；
- 网上报名后按要求缴费，逾期无法补报；
- 一般需要四级达到一定分数（常见为 425 分）后才能报考六级，以当次报名通知为准。

## 分数构成

| 部分 | 内容 |
|---|---|
| 听力 | 短篇新闻、长对话、听力篇章 |
| 阅读 | 选词填空、长篇阅读、仔细阅读 |
| 写作与翻译 | 一篇短文写作、一段汉译英 |

总分 710 分。四六级没有“及格证书”，成绩报告单上只写分数，大家常把 425 分作为四级的“过线”参考。口语考试单独报名，可以按需参加。

## 备考建议

1. **用真题**：近几年的真题是最好的材料，先做一套摸清水平。
2. **听力和阅读占大头**：每天固定练一点，比考前突击有效。
3. **作文与翻译背模板不如多写**：写完对照范文改一遍，效果更好。
4. **早考早安心**：大一下或大二上考完四级，后面的时间可以留给六级和专业课。
