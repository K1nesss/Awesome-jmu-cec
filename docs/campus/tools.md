# 计算机学生常用工具与学生优惠

::: info 关于本文
本文由站点维护者整理通用信息，作为示例文章发布。具体要求以目标学校官网和当年通知为准，欢迎有经验的同学点击页面底部「在 GitHub 上编辑此页」补充。
:::

凭学生身份，很多原本收费的开发工具和服务可以免费使用。下面列出常见的几类，申请条件以各官网为准。

## 学生优惠

| 服务 | 能得到什么 | 一般怎么申请 |
|---|---|---|
| GitHub Student Developer Pack | GitHub Pro 及合作伙伴提供的一批开发工具权益 | 学校邮箱或在读证明认证 |
| JetBrains 教育许可 | IntelliJ IDEA、PyCharm、CLion 等全家桶 | 学校邮箱或在读证明认证 |
| 各大云服务商的学生计划 | 低价或免费的云服务器、云额度 | 学生身份认证 |

## 写代码

- **编辑器 / IDE**：VS Code（免费）、JetBrains 系列（学生免费）；
- **版本管理**：Git，配合 GitHub 托管代码，课程作业和比赛代码都值得放上去；
- **刷题平台**：洛谷、力扣（LeetCode）、牛客等。

## 写论文与报告

- **LaTeX**：Overleaf 在线编辑，模板丰富，毕业论文与竞赛论文常用；
- **文献管理**：Zotero（免费开源），配合浏览器插件一键收藏论文；
- **画图**：draw.io（免费）适合画流程图、架构图。

## 学习效率

- **笔记**：Markdown 编辑器写课堂笔记，方便搜索和导出；
- **网课**：中国大学 MOOC、学堂在线等平台有大量计算机课程。
